Quick start

Install steps

1 Choose platform Install from Google Play or Windows, use the web app on iPhone and iPad until the iOS app launches, and use official university links only.
2 Install or open Android: install from Google Play. Windows: save the installer to your PC, then run it. Open U-Panel from the Start menu after setup. Web: sign in in your browser — no install needed.
3 Sign in Students use @studmc.kiu.ac.ug email. Staff use KIU-#### and the password from your administrator.
